# DL/T 645-2007 帧解析基础（80% 方案）

> 来源：DL/T 645-2007 第 5、6、7 章与附录 C（用户提供）。
> 目的：先把常用帧结构和字段理清楚，再按“覆盖日常调试 80% 场景”的范围实现解析；
> 不追求协议全量实现，冷门/过细的内容明确排除。
> 状态：**Phase A/B 已实现；Phase C（DI 数值解码）暂缓**。

## 一、帧结构

```text
[FE...] 68 A0 A1 A2 A3 A4 A5 68 C L DATA CS 16
```

| 字段 | 长度 | 说明 |
|---|---|---|
| 前导 FE | 0–4+ | 标准建议主站发送前发 4 个 FE 唤醒；本工具允许 0–16 |
| 起始符 68H | 1 | 一帧开始 |
| 地址 A0–A5 | 6 | 每字节 2 位 BCD，低字节在前；`AA` 为缩位寻址通配；`999999999999` 为广播地址 |
| 起始符 68H | 1 | 地址后的第二个起始符 |
| 控制码 C | 1 | 见第二节 |
| 数据域长度 L | 1 | 数据域字节数；读数据 L≤200，写数据 L≤50，L=0 表示无数据域 |
| 数据域 DATA | L | 结构随功能码变化；传输时逐字节 +33H |
| 校验码 CS | 1 | 从第一个 68H 到数据域末尾所有字节模 256 求和 |
| 结束符 16H | 1 | 一帧结束 |

约定：

- 多字节数据项**低字节在前、高字节在后**（如电能量 123456.78 的传输顺序是 78 12 34 56 再 +33H）。
- 数据域在发送时逐字节 +33H，接收解析时先逐字节 -33H。
- 校验和只统计从第一个 68H 到数据域末尾，不含前导 FE、不含 CS 本身。

## 二、控制码

控制码位定义：

| 位 | 含义 |
|---|---|
| D7 | 传送方向：0 主站命令，1 从站应答 |
| D6 | 从站应答标志：0 正确，1 异常 |
| D5 | 后续帧标志：0 无后续，1 有后续 |
| D4–D0 | 功能码 |

常用功能码（应答 = 请求 + 0x80，异常 = 应答 + 0x40）：

| 功能码 | 功能 | 正常应答 | 异常应答 | 说明 |
|---|---|---|---|---|
| 0x08 | 广播校时 | 无应答 | — | 广播地址，命令帧 |
| 0x11 | 读数据 | 0x91 / 0xB1 | 0xD1 | 0xB1 表示有后续帧 |
| 0x12 | 读后续数据 | 0x92 / 0xB2 | 0xD2 | **本工具不实现** |
| 0x13 | 读通信地址 | 0x93 | 无 | 地址域为 AA…AA |
| 0x14 | 写数据 | 0x94 | 0xD4 | 带密码和操作者代码 |
| 0x15 | 写通信地址 | 0x95 | 无 | 地址域为 AA…AA |
| 0x16 | 冻结命令 | 0x96 | 0xD6 | 数据域为 MMDDhhmm |
| 0x17 | 更改通信速率 | 0x97 | 0xD7 | 数据域为速率特征字 |
| 0x18 | 修改密码 | 0x98 | 0xD8 | 原密码 + 新密码 |
| 0x19 | 最大需量清零 | 0x99 | 0xD9 | 密码 + 操作者代码 |
| 0x1A | 电表清零 | 0x9A | 0xDA | 密码 + 操作者代码 |
| 0x1B | 事件清零 | 0x9B | 0xDB | 密码 + 操作者代码 + 事件 DI |

**80% 范围外（不解析，按原始控制码显示）**：

- 0x1C 跳合闸/报警/保电
- 0x1D 多功能端子输出控制
- 0x03 安全认证命令（及 0x83 / 0xC3、SERR）

## 三、异常应答 ERR（附录 C）

异常应答数据域固定 1 字节 ERR（L=1），按位定义：

| Bit | 含义 |
|---|---|
| Bit0 | 其他错误 |
| Bit1 | 无请求数据 |
| Bit2 | 密码错 / 未授权 |
| Bit3 | 通信速率不能更改 |
| Bit4 | 年时区数超 |
| Bit5 | 日时段数超 |
| Bit6 | 费率数超 |
| Bit7 | 保留 |

解析输出：ERR 原始十六进制 + 所有置位的含义列表。

## 四、常用功能的数据域结构

> 以下所有数据域在帧内都已逐字节 +33H；解析前先 -33H。

### 4.1 读数据（0x11）

请求（无后续）：

```text
68 A0..A5 68 11 04 DI0 DI1 DI2 DI3 CS 16
```

正常应答：

```text
68 A0..A5 68 91 L DI0..DI3 N1..Nm CS 16
```

- `0x91`：无后续数据帧；`0xB1`：有后续数据帧。
- 没有满足条件的负荷记录时，L=4，数据域只有 DI。
- 负荷记录请求有额外格式（L=5 带块数、L=10 带时间+块数），属于低频场景，暂不做专门解析，按原始数据展示。

### 4.2 读后续数据（0x12）——不做

- 现代电表较少拆分后续帧，本工具**不实现**读后续数据、SEQ 帧序号和后续帧拼接。
- 0x12 不进入功能码名称表，帧里出现时按未知功能显示，只展示原始数据域。

### 4.3 读通信地址（0x13）

```text
请求：68 AA..AA 68 13 00 CS 16
应答：68 A0..A5 68 93 06 A0..A5 CS 16
```

- 应答地址域和数据域都是 6 字节实际地址。
- 异常时从站不应答。

### 4.4 写数据（0x14）

```text
请求：68 A0..A5 68 14 L DI0..DI3 PA P0 P1 P2 C0..C3 N1..Nm CS 16
应答：68 A0..A5 68 94 00 CS 16
异常：68 A0..A5 68 D4 01 ERR CS 16
```

- 数据域 = DI(4) + 密码(4) + 操作者代码(4) + 数据(m)。
- 密码 4 字节 = `PA`（权限）+ `P0 P1 P2`（密码）。
- 多字节内容同样低位先行。
- 解析输出可拆出：DI、密码权限、密码、操作者代码、数据。

### 4.5 写通信地址（0x15）

```text
请求：68 AA..AA 68 15 06 A0..A5 CS 16
应答：68 A0..A5 68 95 00 CS 16
```

- 应答地址域是新地址；异常不应答。

### 4.6 广播校时（0x08）

```text
68 99..99 68 08 06 ss mm hh DD MM YY CS 16
```

- 广播地址 `999999999999`，不要求应答。
- 数据域低字节在前：秒、分、时、日、月、年。

### 4.7 冻结（0x16）

```text
请求：68 A0..A5 68 16 04 mm hh DD MM CS 16
应答：68 A0..A5 68 96 00 CS 16
异常：68 A0..A5 68 D6 01 ERR CS 16
```

- 广播冻结的周期表示（99DDhhmm / 9999hhmm / 999999mm / 99999999）属于低频细节，暂不专门解释。

### 4.8 更改通信速率 / 修改密码 / 清零（0x17–0x1B）

| 功能 | 请求数据域 | 正常应答 |
|---|---|---|
| 0x17 改速率 | `Z`（1 字节速率特征字） | `Z`（与请求相同） |
| 0x18 修改密码 | DI(4) + 原密码 PA0 P00 P10 P20 + 新密码 PAN P0N P1N P2N | 新密码 4 字节 |
| 0x19 最大需量清零 | PA P0 P1 P2 C0..C3（8 字节） | 无数据域 |
| 0x1A 电表清零 | PA P0 P1 P2 C0..C3（8 字节） | 无数据域 |
| 0x1B 事件清零 | PA P0 P1 P2 C0..C3 + FFFFFFFF（总清零）或 FF + DI1 DI2 DI3（分项） | 无数据域 |

- 这几种功能按“字段拆分 + 原始 HEX”展示即可，不做更深语义解释。

## 五、数据标识 DI

- DI 由 4 个字节组成：`DI3 DI2 DI1 DI0`，十六进制编码；帧内低字节（DI0）先传。
- 数据类型分七类：电能量、最大需量及发生时间、变量、事件记录、参变量、冻结量、负荷记录。
- 单个数据项用唯一 DI 标识；数据块用 FF 占位（DI2/DI1/DI0 任一为 FF；DI3 不出现 FF）。
  - 80% 方案不展开数据块，只按原始 HEX 展示。
- 数据值默认是压缩 BCD；特殊数据项用 ASCII。小数位、单位、倍率由 DI 定义决定。
- 现有 `dlt645-di.json` 已有 `code/name/category/unit/decimals/note`，但没有数据格式/长度字段；
  因此第一版只做 **DI 名称匹配 + 数据 HEX**，数值解码作为后续可选阶段。

## 六、80% 范围（做 / 不做）

### 做

- 帧结构校验与展示（FE、地址、控制码、L、CS、结束符）。
- 控制码 D7/D6 位解释 + 常用功能码完整名称（D5 后续帧不做）。
- 异常应答 ERR 逐位解释。
- 常用功能的数据域字段拆分：
  - 读数据（DI、数据）
  - 读通信地址 / 写通信地址（6 字节地址）
  - 写数据（DI、密码权限、密码、操作者代码、数据）
  - 广播校时（时间字段）
  - 冻结（时间字段）
  - 改速率 / 改密码 / 三种清零（字段 + 原始 HEX）
- DI 名称匹配（使用现有 DI 目录）。
- 长度上限提示（读 >200、写 >50 时给出警告，不阻断解析）。

### 不做（明确排除）

- **读后续数据（0x12）、D5 后续帧标志与 SEQ、后续帧拼接**。
- 0x1C / 0x1D / 0x03 安全认证相关命令。
- SERR 安全认证错误字、状态字、特征字、模式字逐位解释。
- 数据块（FF）展开、负荷记录分块解析。
- 任意 DI 的数值换算（BCD → 工程量、小数位/单位）。
- 多帧自动合并、广播命令的特殊处理。
- 帧间时序、速率切换流程、密码权限业务规则。

## 七、解析输出设计（建议）

### 帧级

```text
原始帧: FE FE FE 68 ... 16
前导 FE: 3
地址: 000000000001（AA 通配 / 广播地址单独标注）
控制码: 0x91（读数据 / 应答）
功能码: 0x11 读数据
数据长度: 6
数据域: ...
传输数据域: ...
校验和: 0xXX（计算值 0xXX，校验通过）
长度检查: 读数据 L≤200 / 写数据 L≤50
```

### 功能级

- 异常应答：`ERR: 0x04（密码错 / 未授权）`
- 读数据应答：`DI: 02010100（A 相电压）/ 数据: ...`
- 读地址应答：`表地址: 000000000001`
- 写数据请求：`DI / 密码权限 / 密码 / 操作者代码 / 数据`
- 校时：`秒 分 时 日 月 年`
- 冻结：`月 日 时 分`
- 其它：原始 HEX + 字段长度提示

### 解析失败

沿用现有具体原因（缺起始符、长度不匹配、校验和错误、缺结束符等），并在错误前标明失败阶段。
